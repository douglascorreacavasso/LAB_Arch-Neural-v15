## 🚀 Auto Desktop/Mobile Detection

Open **`index.html`** in any browser:
- 💻 **Desktop/large tablet:** loads full UI with 3D brain + side panels
- 📱 **Phone/small screen (<768px):** auto-redirects to `mobile.html` — touch-friendly UI

To force desktop on mobile: append `?desktop=1` to URL.
